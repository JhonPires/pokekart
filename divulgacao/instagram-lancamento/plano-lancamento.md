## Destaques e stories

Ordem sugerida: **Comece aqui · Gameplay · Karts · Pistas · Torre · Novidades**.

Os seis PNGs de `destaques/` são capas 1080 × 1920, com ícones centrados para recorte circular. Os seis PNGs de `stories/` são aberturas dos respectivos destaques. As capas não substituem os stories de conteúdo.

Publicar os stories de abertura e, depois, adicioná-los aos destaques correspondentes. Aplicar a capa com o mesmo nome. Se a conta oferecer arquivo de stories, mantê-lo ativo para facilitar atualizações posteriores; não alterar essa configuração sem verificar o estado atual.

Stickers para inserir manualmente, sem textos que finjam ser botões:

- Comece aqui: sticker de link para o site oficial, título “Conheça o projeto”.
- Karts: caixa de perguntas “Qual Pokémon você quer na pista?”.
- Pistas: enquete “Curvas ou retão?”, respostas “Curvas” / “Retão”.
- Torre: pergunta “Qual líder você quer enfrentar?”.
- Gameplay: abertura; adicionar depois um vídeo real de corrida. A arte de abertura não é gameplay.
- Novidades: sticker de link para o site; registrar novidades reais do desenvolvimento.

Não usar contagem regressiva enquanto a data não estiver definida. Não anunciar “lançado”, “jogue agora” ou disponibilidade de uma atualização que ainda não foi conferida no site.
