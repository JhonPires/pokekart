# Vozes dos Pokémon

Coloque aqui os MP3s escolhidos no Voicy, usando o ID do kart como nome do arquivo:

- `pikachu.mp3`
- `charizard.mp3`
- `jolteon.mp3`
- `gengar.mp3`
- `eevee.mp3`
- `arcanine.mp3`

O mesmo padrão vale para os demais Pokémon. O jogo usa automaticamente o arquivo
local, sem alterar a HUD e sem depender do Voicy durante a corrida. Se o arquivo
não existir ou não puder ser reproduzido, mantém o som anterior da PokéAPI.

Prefira um trecho curto com somente a voz do Pokémon, sem música ou diálogo de
outros personagens. Recarregue o jogo depois de adicionar um arquivo.
